## 🧐 About The Project

**EventTracker Pro** is a modern, high-performance web application designed to help users plan, organize, and track events effortlessly. Built with a robust **Node.js & Express** backend and styled with a sleek **Tailwind CSS dark UI**, it offers secure user authentication, interactive dashboard metrics, custom scheduling, and dynamic popularity sorting.

Whether you're organizing a small birthday bash or a college tech fest, EventTracker Pro keeps your data organized and accessible in real-time!

---

## ✨ Key Features

- 🔐 **Secure JWT Authentication:** Isolated user sessions with encrypted JSON Web Tokens and password protection.
- 📊 **Real-Time Analytics:** Live dashboard cards calculating **Total Events**, **Total Participants**, and **Top Popularity** scores instantly.
- 🗓️ **Date & Time Scheduling:** Built-in datetime selector to schedule upcoming events precisely.
- 🏷️ **Status Workflow:** Dynamic badges indicating event progress (`Pending` vs `Completed`).
- 🔍 **Instant Search & Sorting:** Real-time client-side search filtering and single-click sorting by event popularity 🔥.
- 🛡️ **Role-Based Ownership Control:** Users can only modify or delete events created under their account, while viewing global events in read-only mode.
- 🌙 **Sleek Dark Theme UI:** Pixel-perfect, fully responsive glassmorphism UI built with Tailwind CSS.
